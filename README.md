# Cisco CCNAv7: Switching, Routing, and Wireless Essentials (SRWE)

Repositório dedicado ao armazenamento de anotações teóricas, comandos de configuração de CLI e topologias práticas desenvolvidas no **Cisco Packet Tracer** durante o módulo **CCNA 2 (SRWE) desenvolvidos em aula**.

---

### 📌 Conteúdo Abordado

* **VLANs & Trunking:** Configuração de VLANs, enlaces Tronco (802.1Q), DTP e Roteamento Inter-VLAN (Router-on-a-Stick e Switch Camada 3 / SVIs).
* **Redundância em Camada 2:** Spanning Tree Protocol (STP, RSTP, PVST+) e agregação de links com EtherChannel (LACP/PAgP).
* **Segurança de Camada 2:** Mitigação de ataques em switches (Port Security, DHCP Snooping, Dynamic ARP Inspection - DAI).
* **Serviços de Rede:** Configuração e resolução de problemas com DHCPv4 e SLAAC / DHCPv6.
* **Redes Sem Fio (WLAN):** Conceitos de redes wireless, configuração de APs autônomos e controladores WLC.
* **Roteamento Estático:** Rotas estáticas padrão, flutuantes e sumarizadas para IPv4 e IPv6.
